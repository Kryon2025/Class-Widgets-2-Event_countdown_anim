# 事件倒计时动画开关 / Event Countdown Animation Toggle

为 Class Widgets 2 **内置"事件倒计时"组件**（显示距离下课 / 课间剩余时间的组件）添加**动画开关**的扩展插件。

## 背景

内置"事件倒计时"组件的分钟/秒数字使用 `AnimatedDigits` 滚动动画，且组件本身没有编辑界面，无法关闭动画。

官方插件 API 无法为已注册的内置组件追加编辑页（同名注册仅更新名称、不覆盖设置页），因此本插件采用以下方式实现：

1. 加载插件时，对主程序 QML 资源（`src/qml/widgets/eventCountdown.qml`）打**可逆补丁**，使组件支持动画开关（**先备份原文件**）；
2. 在主程序设置页（TTS 服务同款模式）提供"动画效果"开关；
3. 卸载插件时**自动恢复**主程序原始 QML，内置组件不受影响。

## 使用

1. 导入本插件；
2. 如组件未立即生效，**重启 Class Widgets 2**（组件缓存原因，卸载后同样需重启恢复）；
3. 打开 **主程序设置 → 插件设置 → 事件倒计时动画**，切换"动画效果"开关；
4. 开启 = 数字滚动动画；关闭 = 静态显示。切换后组件约 0.3 秒内实时生效。

## 行为说明

- 安装插件：内置组件出现动画开关能力（设置位于主程序设置页）；
- 卸载插件：主程序 QML 自动恢复原始文件，编辑功能随之消失，内置组件本身不受影响；
- 主程序升级/重装会覆盖 QML 补丁：重新导入一次插件即可重新打补丁（原文件已备份，不会重复备份）；
- 若组件 QML 路径不存在（如主程序目录结构变化），插件会跳过补丁并仅保留设置页，不影响主程序运行。

插件基于 Class Widgets 2 SDK **0.6.0**（`api_version: ~=0.6.0`）。
